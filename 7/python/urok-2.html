Контрольні запитання

Чому для комп’ютера не підходить звичайна людська мова?

Вона неоднозначна: одне слово може мати кілька значень. Комп’ютеру потрібна формальна мова, де кожна команда має одне точне значення.

Чим компілятор відрізняється від інтерпретатора?

Компілятор перекладає всю програму й створює готовий файл. Інтерпретатор перекладає та одразу виконує команди по одній і зупиняється на першій помилці.

Назви дві мови високого рівня й одну мову низького рівня.

Високого: Python, Java, JavaScript, C++, Scratch… Низького: машинний код або асемблер.

Опорний конспект · Урок 2

Середовище програмування (IDE)

Програма, яка поєднує редактор коду, засоби запуску програм, пошуку помилок і роботи з файлами.

Два режими роботи

  • Інтерактивний (Shell, запрошення >>>): команда виконується одразу після Enter, нічого не зберігається.
  • Режим програми: код пишуть у файлі .py, зберігають і запускають скільки завгодно разів.

IDLE (встановлюється разом із Python)

File (Файл) → New File (Новий файл) → код → File (Файл) → Save (Зберегти) hello.py → Run (Запуск) → Run Module (Запустити модуль) або F5 → результат у Shell.

Thonny (Python уже вбудований)

  • Редактор угорі, Shell унизу, Variables (Змінні) праворуч: View (Вигляд) → Variables.
  • Run (Запуск): зелена кнопка або F5.
  • Покроково: Debug (жучок), далі Step over (Крок через), F6.

Онлайн: pythonny.pp.ua

Працює в браузері на будь-якому пристрої, нічого не треба встановлювати. Потрібен інтернет. Зберігай свій код!

Повідомлення про помилку

  • Де? — line 2: номер рядка.
  • Що? — тип: SyntaxError (порушено правила запису), NameError (невідоме ім’я).
  • Як виправити? — читай пояснення і дивись на ^.

Як працювати з конспектом удома (≈ 10 хв)

  1. Прочитай конспект і по пам’яті запиши в зошит послідовність дій для створення й запуску програми в IDLE або Thonny.
  2. Відкрий Thonny, IDLE або pythonny.pp.ua та в інтерактивному режимі обчисли три вирази: 365 * 24, 1000 - 7, 2 ** 8. Запиши результати в зошит.
  3. Дай усні відповіді на запитання: чим інтерактивний режим відрізняється від режиму програми? Які три запитання треба поставити до кожного повідомлення про помилку?

Практичне завдання: «Програма-візитівка»

У будь-якому середовищі (найкраще в Thonny або pythonny.pp.ua) створи програму vizytka.py, яка виводить твою візитівку в рамці з зірочок: ім’я, клас і хобі.

Приклад коду
print("*************************") print("* Ім'я: Оля Коваль *") print("* Клас: 7-А *") print("* Хобі: малювання *") print("*************************")
Очікуваний результат
************************* * Ім'я: Оля Коваль * * Клас: 7-А * * Хобі: малювання * *************************

Критерії виконання:

  • файл збережено з назвою латиницею і розширенням .py;
  • у програмі щонайменше 5 команд print;
  • програма запускається без помилок;
  • є рамка з зірочок, а в рядках — твої дані.

Зроби знімок екрана, де видно код і результат. Здай його так, як домовились з учителем. На початку наступного уроку буде розбір типових помилок.

Місток до уроку 3

Твоя візитівка складається з кількох однакових команд print. На наступному уроці дізнаєшся, що print() уміє набагато більше: виводити кілька значень одразу, текст разом із числами, змінювати розділювачі. А ще познайомишся зі змінними — «скриньками», у яких програма запам’ятовує дані.

Подумай до уроку: як зробити, щоб твоє ім’я в програмі можна було змінити в одному місці, а воно змінилося в усіх рядках?
