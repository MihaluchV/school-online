# Інформатика 5–11 · school-online

Сайт учителя інформатики з уроками, презентаціями, тренажерами й контрольними роботами для 5–11 класів.
Працює на GitHub Pages: **https://mihaluchv.github.io/school-online/**

## Структура репозиторію

```
index.html      — сайт для учнів
admin.html      — кабінет учителя (редагування змісту, завантаження файлів)
style.css       — стилі сайту
admin.css       — стилі кабінету вчителя
art.js          — мальовані обкладинки розділів
app.js          — логіка сайту
admin.js        — логіка кабінету вчителя
catalog.json    — увесь зміст сайту: класи → розділи → теми → матеріали
config.js       — налаштування Firebase (той самий проєкт, що в Клас-коді)
firebase-rules.json — спільні правила бази (копія; публікуються в консолі Firebase)
.nojekyll       — вимикає зайву обробку на GitHub Pages
README.md

5/  6/  7/  8/  9/  10-11/     — матеріали за класами
   9/databases/zoo-modeling-trainer.html
   9/python/spysky-trainer.html …
img/                           — власні обкладинки розділів (якщо замінюєте мальовані)
```

Файли сайту лежать у корені. Матеріали лежать у папках класів і підпапках розділів (назва підпапки збігається з «Папкою розділу» в кабінеті).

## Перше розміщення

1. Завантажте всі файли з архіву в корінь репозиторію `school-online` (Add file → Upload files).
2. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Приблизно за хвилину сайт буде доступний за адресою вище.

## Кабінет учителя

Адреса: **https://mihaluchv.github.io/school-online/admin.html** (на сайті посилання на нього немає, додайте в закладки).

### Єдиний вхід

Кабінет використовує ту саму базу Firebase **school-3-online-edu** і ті самі облікові записи вчителя, що й «Клас-код» та «Групова робота» (логін або пошта плюс пароль).
Після входу в кабінет обидві платформи відкриваються кнопками на верхній панелі вже без повторного входу. Кнопка «Вийти» виходить з усіх трьох.
Реєстрація та зміна пароля відбуваються в «Клас-коді»; у кабінеті є «Забули пароль?».

### Налаштування (один раз)

1. **Правила Firebase.** Відкрийте Firebase → Realtime Database → Rules, вставте вміст `firebase-rules.json` з цього архіву → Publish.
   Це ті самі правила, що для «Клас-коду» та «Групової роботи», з доданим розділом `hub` для кабінету сайту. Їх треба оновити й у репозиторіях `online-education` та `online-group`, щоб усі три копії файлу збігалися.
2. **Адміністратор.** Одразу після публікації правил увійдіть у кабінет і натисніть «Так, я адміністратор». Першим, хто це зробить, буде ваш обліковий запис. Інші вчителі зможуть увійти, але керувати сайтом не зможуть.
   Змінити адміністратора можна лише в консолі Firebase: вузол `hub/owner`.
3. **Токен GitHub** (потрібен, щоб кабінет записував файли в репозиторій):
   1. GitHub → аватар → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
   2. Token name: `school-online`; Expiration: наприклад, 1 рік.
   3. Repository access: **Only select repositories** → `school-online`.
   4. Permissions → Repository permissions → **Contents: Read and write**.
   5. Generate token → скопіюйте (`github_pat_…`) і вставте в кабінеті з позначкою «Зберегти в моєму обліковому записі».

   Токен зберігається в базі під вашим обліковим записом, і прочитати його можете лише ви. На іншому комп’ютері кабінет підключиться до GitHub сам після входу. Коли строк токена мине, створіть новий і введіть його через «Налаштування GitHub».

### Що можна робити в кабінеті

- **Розділи:** додавати, перейменовувати, змінювати порядок, обирати обкладинку або завантажувати власне зображення, видаляти.
- **Теми:** додавати, змінювати порядок, описувати, видаляти.
- **Матеріали теми:** Теорія, Презентація, Відеоурок, Тренажер, Контрольна.
  - Кнопка **«Завантажити файл»** відкриває вибір файлу на комп’ютері (наприклад, `index.html` тренажера). Кабінет пропонує правильне ім’я та папку, наприклад `9/databases/zoo-modeling-trainer.html`. Шлях можна змінити. Файл одразу потрапляє в репозиторій, а матеріал з’являється на сайті.
  - Замість файлу можна вказати повне посилання `https://…` (наприклад, на YouTube чи Google Презентацію).
  - Позначка **NEW** показує матеріал на головній сторінці в «Нових матеріалах».
- **Контрольні роботи:** вкладка з перемикачами «відкрито / закрито» для всіх контрольних. Закриту контрольну учні бачать з позначкою «закрито», але не можуть відкрити.
- **Класи і платформи:** назви й кольори класів, кнопки входу на платформи (Клас-код, Групова робота).

Після збереження сайт оновлюється приблизно за 1–2 хвилини.

Без токена кабінет теж працює («Працювати без GitHub»): після змін натисніть «Завантажити catalog.json» і замініть ним файл у репозиторії вручну.

> Закрита контрольна прихована лише на сайті. Хто знає точну адресу файлу, все одно може його відкрити, бо GitHub Pages не має паролів. Для важливих контрольних тримайте файл поза репозиторієм до початку роботи або завантажуйте його перед уроком.

## Правила назв файлів

- Лише латинські літери, цифри, дефіс і крапка: `spysky-trainer.html`.
- Кабінет сам переводить кирилицю в латиницю.
- Повторне завантаження файлу з тим самим шляхом замінює стару версію (зручно для оновлення тренажера).

## Перенесення старих тренажерів

Поки файли лежать в окремих репозиторіях, матеріал може посилатися на стару адресу (`https://mihaluchv.github.io/modeling-db-zoo/`). Щоб перенести тренажер: у кабінеті натисніть **«Завантажити файл»** біля матеріалу, виберіть його `index.html`, і посилання заміниться на новий шлях. Старий репозиторій краще залишити, доки учні користуються старими посиланнями.

Запис у Google-таблицю через Apps Script працюватиме й після перенесення.
